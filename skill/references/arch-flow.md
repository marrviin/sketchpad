# 手绘架构图 / 流程图 · 领域知识

> 配套 stencil：`db` `server` `cloud` `actor` `group`。节点形状决定"一眼懂不懂"，先定 stereotype 再连线。

## 节点 stereotype → 画法对照

| 含义 | 画法 | 备注 |
| --- | --- | --- |
| 应用服务 / 微服务 | `rrect` 圆角框 | 主力节点，框内手写名称 |
| 数据库 | `stencil kind:"db"` | 圆柱，别用方盒子代替 |
| 缓存（内存库） | `db` + 名称写 "cache" 或外面套 `dash` 虚线 | 与持久库区分 |
| 服务器 / 后端机 | `stencil kind:"server"` | 堆叠机架 |
| 外部系统 / 第三方 | `stencil kind:"cloud"` | 云形 |
| 消息队列 / 存储桶 | `rrect` + 名称标 MQ / Bucket | 或三条横线的盒子 |
| 参与者 / 用户 | `stencil kind:"actor"` | 用例图、时序图 |
| 子系统分组 | `stencil kind:"group"` | 虚线大框 + 左上角标题 |
| 边界 / 隐藏层 | `dash` 线条 | 与实线区分 |

## 布局

- **方向**：自上而下（分层清晰，如 App→服务→DB）或自左而右（流程/调用链）。一张图只用一个主轴。
- **先数节点再定坐标**：竖排 n 个节点 → pitch = (620 − 上下边距×2) / n 算出 **px**，别用 norm 随手拍 0.07/0.21/0.35。norm 下 h 按宽缩放，纵向间距极易算错变拥挤。主脊柱水平居中（如盒 x=370 w=300 → 中轴 520）。
- **机制/后台步骤不进主流程**：如"SSE 渲染 / PUT 落盘"是机制不是用户动作 → 降级为旁边虚线旁注（`stencil kind:"group"` 虚线框 + `dash` 连线指到对应节点），主流程只画动作节点。
- **分层配色**（颜色是层级语义，不是装饰）：
  - `ink` 墨黑 = 应用 / 我们的代码
  - `ink-you` 蓝 = 客户端 / 浏览器 / 前端
  - `grape` 紫 = 中间件 / 网关 / 消息总线
  - `teal` 青 = 数据存储（DB、缓存）/ 机制旁注
  - `red` 红 = 外部三方 / 不可控依赖
- **泳道**：横向分组就用 `group` 虚线框把每层包起来，标题写"前端层 / 服务层 / 数据层"。

## 文字标注

- **节点标签单行**：一个盒只放一行 ≤12 字，盒高 ~48px、字号 ~18、**垂直居中**（y = 盒顶 +15）。要解释机制就放旁注，别往盒里塞两行。
- **水平居中**：标签按盒中心反推 x（CJK 字宽≈字号、ascii≈字号×0.55），别左对齐贴边。

## 箭头与连线

| 关系 | 画法 |
| --- | --- |
| 同步调用 / 请求响应 | 实线 `arrow`（有方向） |
| 异步 / 事件 / 推送 | `arrow` 但主干用 `dash`，或旁边手注 "event" |
| 双向（如 SSE 推送 + PUT 回流） | 两条平行、方向相反的 `arrow`，分别标注 SSE / PUT |
| 无方向关联 | 普通 `line`（无箭头） |
| 依赖 / 引用 | `dash` 虚线箭头 |

- **箭隙 ≥30px**：节点间箭头长度 32~40px 才自然，短 stub（20px）显拥挤。
- **迭代回路用紧贝塞尔**：回路从节点右侧出去，用单段 `bezier`（不是 spline 过点、不是直角 polyline）绕回上游节点——**鼓出控制在 ~60px 内**（相邻节点间距 80px，回路别比间距还宽），末端两笔当手绘箭头尖。spline 过点会过冲抖动、易鼓成大圈。
- 箭头说明文字放**线旁**，别压在框上。

## 图例块

图大时在角落画一个小图例：每种 stereotype 一个小样 + 手写一行说明。用 `group` 框住图例区。

## 常见错法

- 所有节点都是同一个 rrect → 看不出谁是库谁是外部系统。**抽象符号一律用 stencil，别手搓圆柱/云。**
- 节点塞两行字 / 文字左对齐贴边 → 标签单行、盒内水平+垂直居中（见"文字标注"）。
- 回路画成直角折线或 spline 大圈 → 用紧 `bezier`（鼓出 ~60px），手绘风不要直角、不要大圈。
- 机制步骤（SSE/落盘）混进主流程 → 降级为虚线旁注，主流程只画用户动作。
- 箭头挤在一根线上来回绕 → 同层节点横向对齐，回路走外侧。
- 框压线（norm 高度换算坑）→ 框高按 `h = 期望px/1040`，纵向间距算足。
