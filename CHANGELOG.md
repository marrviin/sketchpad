## [0.1.0] - 2026-11-23

### Added

- Hand-drawn canvas with REST/SSE backend and CLI (`sketchpad`); agent draws strokes/texts/icons, human watches in real time.
- Viewer-only page: pan, zoom, multi-canvas switching, narrative replay.
- Scene compose tools: flowchart, sequence diagram, and multi-screen wireframe layout (`compose`), with serpentine wrap and geometric edge routing.
- Geometry lint tool (`lint`) with aggregate issue reporting.
- Named element groups and replay choreography via order levels.
- Right-click export: PNG image and video (fixed 16:9 frame).
- Claude skill with the full draw → self-check → refine workflow.
- Built-in icon shapes, symbol stencils (phone / browser / db / server / cloud / actor / group), and LXGW WenKai handwriting fonts (OFL).
